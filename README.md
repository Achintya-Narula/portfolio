# Achintya Narula Portfolio

A one-page portfolio for my software, AI/ML, GenAI, and student-community work.

## Stack
Next.js, React, TypeScript, CSS, Vitest, Vercel.

## Local development
```bash
npm install
npm run dev
```

## Verification
```bash
npm run test:run
npm run typecheck
npm run lint
npm run build
```

## Privacy
The public site and downloadable resumes intentionally omit my phone number and exact location.
The site provides email links instead of a contact form and does not intentionally run
behavioural analytics.

The production-origin test scans generated HTML and CSS after a build. Initial scripts,
styles, fonts, images, and embedded resources must remain on the configured site origin.
Normal user-activated links to GitHub, LinkedIn, and project repositories are allowed.

## Deployment
The production site is deployed through Vercel from the `main` branch.
